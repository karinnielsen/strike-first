# Pixel board sprites — experiment

Prepared against main `83415dba4909cf7b50a530d7e2ee769ed41a6ad9`, ASSET-BRIEF §7a and §9. **For Claude to review and integrate by hand.** This commit only adds artwork and review tooling. No game changes.

`sprites.js` is the canonical inlineable palette/character data. `.` is always transparent. Open `preview.html` locally to inspect native size, all four directions and facial states. PNGs and SVGs are generated proofs, not runtime dependencies. `preview.png` places actual-size sprites above enlarged versions. Run `node design/pixel-sprites/verify.cjs` from the repository root.

## Coordinates and layers

- Egg, rotten egg, mouse, body and tail: **10×10 art pixels → 20×20 screen pixels**, pivot `[5,5]` measured from the top-left grid edge. Occupied boxes: egg 6×8, rotten 10×10, mouse 10×8, body/tail 8×8 art pixels. Empty margin is intentional.
- Head: **18×18 padded shared canvas → 36×36 screen pixels**, pivot `[9,9]`. The ordinary 10×10 cell starts at `[4,4]`. Place the assembly's top-left at cell-centre minus `[18,18]` screen pixels. Do not stretch this entire canvas into a cell. Head flesh occupies 7×7 pixels; the hood is 7×13 (14×26 screen pixels); the tongue reaches outside the cell. Padding is not extra sprite detail.
- Draw head parts in this order: `hood`, `markings`, `tongue` if visible, `head`, then exactly one of `eyes-open`, `eyes-blink`, `eyes-defeated`. Every part has its own palette and square grid, with identical origin and dimensions. Recolour `b`/`s` for illness; preserve red and eye colours.
- Head faces right. Rotate the entire assembly around its pivot by multiples of 90°; do not rotate layers around individual bounds. Mouse faces right; mirror its full grid for leftward travel.
- Tail's **tip is left**, body connection right: this is the trailing end of a right-moving snake. Rotate to follow the preceding segment. Body and tail share the same outer box; taper cuts inward and never advances the tip into a neighbour's cell.

## Integration decisions / deliberate exceptions

1. **Head canvas exceeds 10×10.** Required to preserve the explicitly permitted 26px hood and an extended tongue on one coordinate grid. The flesh remains smaller than one cell. This uses §7a's hood exception, not 18×18 detail squeezed into 20px.
2. **“Largest thing on the board” conflicts with the permitted 26px hood.** Rotten egg fills the full 20×20 cell and is the largest food and ordinary segment. The hood and extended tongue remain the specified exceptions. Do not enlarge the hazard's footprint further without Karin's decision.
3. **Single-colour body/tail use two palette entries including transparency.** This follows their specific recolouring requirement over the general four-to-six-colour minimum. The head uses six entries shared across its parts; individual state layers naturally use fewer. Egg uses four, rotten five, mouse six.
4. **Colours:** rotten shell is exactly `#a8c341`, rim `#454f1c`, crack `#2f3614`, highlight/vapor green `#b2d65c`. Egg shell/rim retain `#f4e8cf` / `#c9a227`; its highlight uses the brief's `#ece6da` instead of pure white. Mouse retains fur `#b89a7e`, shadow/tail `#8a7461`, ear `#d9938a`; muzzle borrows existing egg cream `#f4e8cf` **for a new anatomical meaning**, flagged for review. Head retains current main's `#f8f4ea`, `#cec6b2`, gold eyes and red markings/tongue. Most are existing drawing colours outside the CSS token table, not newly invented hues; Claude should confirm these retained exceptions before integration. Gold remains egg reward edging and existing cobra eyes. No new belt colour is introduced.
5. **Motion stays in code.** Preserve tongue timing (280ms / 2600ms), treat-ahead extension and queasy hold; blink 130ms / 4200ms; defeated eyes override blink. Pixel forks approximate the existing ±2.5px prongs with whole 2px blocks. Quantise shudder to 2px increments. Smooth scaling of the egg pulse would violate the art grid: use discrete pixel-size states or a highlight pulse after review. Retain green rising vapor as whole-pixel runtime particles behind the rotten egg; a soft blurred cloud cannot satisfy this pixel constraint. No replacement animation logic is proposed by the artwork.
6. **Spacing needs a runtime choice.** Keep existing CELL=20 centres and the existing taper calculation `(CELL-2)-7*t`. This 8×8 body mask is an art template, not a request to use uniform 16px segments. Current 18→11px sizes cannot all be represented by 2px pixels while retaining exact centred edges. Claude should choose quantised extents/placement with Karin; do not silently change grid spacing or stretch the mask to fractional pixels. Recolour the designated belt segment using existing rank logic.
7. §7a's character grids supersede the generic SVG-source requirement. SVG proofs are included anyway: flat pixel rectangles, viewBox, no fonts, IDs, filters or external references. `snake-head.png` is the intended 36px padded assembly; `snake-head-cell.png` is its exact 20px cell crop, **not** a shrunk or complete head.

The tilt and one-art-pixel crack are baked into the rotten silhouette. Do not rotate it by a fractional angle. The mouse uses an ear, long muzzle and trailing tail to avoid the egg silhouette. All proofs use nearest-neighbour enlargement.
